# 一、实现
- `app.js` 在整理执行期间保留实际圆环，正常报告先发布，再启动完成后的下降。到零调用现有只读显示接口，读取失败保留状态，不能重试清理
- `cleanup-effect.js` 只管理750毫秒下降、等待一次新读数和300毫秒回弹，去掉最短观察、连续样本及稳定阈值。轮次隔离阻止旧读取驱动新动画
- 回弹结束取消未结束的实际数值插值并接回最新快照，避免旧绘制帧将圆环重新拉高。实际结果、原始报告及清理控制不属于动效
- 主窗口布局与桌面未改，Package、系统调用、HTTP端点及业务完成时机保持。README同步当前顺序与真实网页交付约定
