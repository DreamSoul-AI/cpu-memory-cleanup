# 一、改动与取舍

新增Windows当前用户NSIS安装候选，复用已有无控制台入口及网页，开始菜单和可选桌面快捷方式指向真实程序。安装目录与用户运行记录分离，卸载保留记录。构建脚本记录版本、build_id和产物SHA256，不自动安装编译器或发布。

新增Linux系统适配：从/proc读取容量、提交量与进程信息，以boot_id和starttime识别实例。系统层分别暴露读取能力与整理能力，HTTP会话和网页遵从该能力，Linux只读时禁用维护及规则启用，不伪装清理。新增Linux便携打包脚本，产物提供实际CLI和run.sh。

Windows默认清理实现、750毫秒下降、回弹和持续读取保持原合同。Codex通过既有六工具接口完成一次真实自有负载任务，说明当前直接CLI已能接入，不为此次任务另建MCP服务。
