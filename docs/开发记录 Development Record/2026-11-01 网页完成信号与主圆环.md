# 一、职责与实现
网页主圆环平时显示实际占用，操作时显示明确标注的过程动效：从起始占用三秒线性归零，等待本次整理成功终态，再回弹。最新有效读数持续跟踪，在回弹开始时固定该段终点；回弹结束恢复实时主圆环。实际百分比、容量、横条及读取时间另区更新，动效不写入这些数据或原报告。

cleanup-effect.js只拥有视觉阶段和时钟。app.js接收完成报告后先公布结果，再通知动效；不在finally中把失败当成功。后台较快时结果先出现，圆环仍可继续归零；后台较慢时圆环停在过程零位，不能据动画结束提前宣布成功。动效可关闭，业务不等动画，也不从动画判断是否再次派发。

网页工作集入口不再强制传入三秒后续观察参数，采用公共API默认的即时前后快照与安全收尾。三秒是视觉归零时长，不是系统完成期限。原生维护命令、权限、互斥、记录格式、公共API、CLI及桌面参数均未修改，仍只有一次清理调用。停止后续观察并不代表停止独立的持续读取。
