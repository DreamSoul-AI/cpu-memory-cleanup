# 一、交付范围与原因
上一阶段只有独立假数据启动脚本，没有正式网页装配入口。本轮补齐正式网页到Package的操作系统后端选择路径，保留独立假数据入口与醒目的模式说明，避免将localhost本身等同于真实接入。启动和页面打开不自动采样，正式接口没有假数据回退。

# 二、实现与职责
- api的create_web_server默认装配真实Application；CLI新增互斥的--web与端口配置，网页HTTP与CLI并列使用同一Package，不用网页转调shell。
- application维护目标身份、批次、保护与规则；系统层提供真实路径和记录存储；HTTP只传递有限请求、串行调度和查询。完整程序文件路径用于分组，不宣称完整应用关联。
- 网页接入搜索、排序、多选、批次、路径/实例保护与保存、逐项结果和离线回看。全局工作集与高级Standby不能支持保护名单，执行前独立说明与确认。
- 定时或持续压力规则默认关闭，启用需明确确认并固定目标/保护快照。持续条件、冷却和互斥经注入时钟验证；停用与取消阻止后续派发，不撤销已发生动作。重启只恢复配置，不恢复武装。
- 服务退出先停规则、拒绝新任务并收尾。原Tk/托盘原型后置保留，不新增系统服务或开机任务，不进行桌面Computer Use验收。
- 静态Demo增加合成目标与保护旅程。候选版本0.3.0带网页资源进入wheel/sdist，API/工具版本及原记录语义保持兼容，增加的批次索引独立管理版本。

# 三、验证中修正
规则判断与实际提交之间可能收到停用或替换配置，本轮增加同一锁内的武装和策略身份核对，防止旧触发继续派发。自动批次结果独立于内部压力观察任务，后续状态读取不覆盖最近动作，页面只在任务终态标记结果已展示。针对这些行为补入HTTP与注入时钟测试。
