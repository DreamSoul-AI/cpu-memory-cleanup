# 二、职责和实现
- 系统接入：WindowsBackend内部选择P1或P2，默认P1不变；复用同一TargetSession、目标权限、身份/路径检查及前后读数。P2参数使用指针宽度SIZE_T(-1)，原生失败保留错误，不回退其他动作。动作和预写意图保存native_method
- 功能与记录：逐项证据区分原生耗时、目标核验和业务耗时，批次另计墙钟。比较摘要保存处理覆盖、未知与失败，不把逐进程工作集差额累加成整机收益。批次附件写入位于原业务收尾后，附件失败不改变已发生动作；离线回看从原子记录重建摘要
- 实验准备：MemoryObserver仅接收只读回调，与调用线程分开，使用自身单调时间轴及显式动作标记。保存实际间隔、错误和超预算。controlled_load仅分配自有缓冲并固定触页，以标准输入read/quit完成读回或自然退出；不查找其他进程、不采样或自动整理主机
- 边界：没有公共API参数、CLI/Tool/HTTP动作或新依赖；产品全局主按钮、网页/桌面/动效及自动规则均未修改。内部实验设施不是已集成的产品性能模式
