# 一、实现

新增可选desktop-window特性和memory-cleanup-window入口，窗口职责落于interaction/desktop。Wry/Tao承载原网页，业务仍经同一Application和Win32接入。原型默认14801，不替换已发布浏览器14800入口；WebView用户配置位于用户LocalAppData目录。重复实例共享端口标识，不再次建立业务服务；内嵌窗口限制为自身本地地址。

新增可克隆WorkbenchControl，网页停止和窗口关闭共用停止逻辑；服务拒绝新任务、取消后续步骤，等待已派发动作和记录收尾后退出，不强杀进程。测试覆盖在途任务收尾。构建脚本复制GNU必需的WebView2加载器；安装器显式接收匹配窗口构建时才创建窗口入口，同时保留浏览器入口。
