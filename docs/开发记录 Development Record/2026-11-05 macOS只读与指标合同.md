# 一、实现与依据

根据托管Mac原生统计证据，新增system/macos中的memory、processes及装配模块。固定libc0.2.191提供ABI定义，容量使用sysctl/Mach，进程使用libproc的秒/微秒创建身份。读取不启动命令行子进程，Mach发送权在作用域结束释放，未实现主动整理。

Memory提交字段改为Option，新增可用量口径与可选压缩驻留。Mac可用量明确为free+inactive估算，页面显示估算并保留未提供的提交字段；Windows/Linux原有数字保留。Rust结构体初始化因此变化，属于未发布候选API，不回签v0.4.0发布物。

新增Mac便携打包和真实探针。探针从含空格解压路径调用产品CLI、启动服务、用目标Mac原生Chrome实际渲染并截图、核对规则关闭和停止。工作流通过不能代替产品通过，当前已要求产品读取和身份、HTTP与页面均成功。
