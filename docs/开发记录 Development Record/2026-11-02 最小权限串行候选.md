# 一、职责与实现
先更新架构的身份/覆盖合同，再将串行调度移到 system/workingset.rs，Win32 接入保留权限映射、原生计时和句柄所有权。默认与候选共用同一循环，避免各自实现取消、结果和关闭。默认行为保持。

最小权限全局候选只申请 SET_QUOTA，省去查询及身份读取，记录明确标记身份仅由已打开句柄关联，created_at 不补值。定向与批次强制走原核验分支，不能借候选装配削弱身份和路径保护。

# 二、装配与验证
experimental-quota 是非默认 Cargo feature，必须显式构造候选并注入 Application。CLI、HTTP、默认工厂和规则没有新增选择入口，绿色按钮与动效未改。默认和候选各25项 Rust 检查、26项网页检查通过，两份 release 和候选源码包验证完成。

统一脚本明确运行库和全部集成用例，不执行零用例 GUI 测试程序，保留全目标静态编译与 GUI 构建。首次系统拒绝启动的失败事实单列记录，没有改变防护。
