- 文档日期按北京时间，运行 ID 中的 UTC 日期保持原样。跨日执行按原正文解释，文件日期不替代精确时刻
- 新日期新建文件，同日有独立主题时增加主题后缀。索引只放链接和简短范围，不累加完整执行正文
- `.test-results/` 中的原始报告继续保持忽略，不因文档归档重新运行、恢复已删除日志或发布产物
