# 三、失败、保留与纠正
- 窗口初次迁移构建遇到过程宏 DLL 被临时占用，确认没有在途构建后单作业重试成功；NSIS 首次读取窗口 EXE 失败，重新确认文件后构建成功。失败原件保留，没有关闭安全防护或改变依赖版本。
- .local/mingw64 中 addr2line.exe、elfedit.exe 在再次检查时不可访问，一次原样复制返回 access denied。没有推定告警来源或绕过限制，按计划停止受影响项，保留 `.test-results/iteration-20261105/window-toolchain/mingw64/` 整个旧副本约 72.8 MiB。本轮编译实际所需 as.exe 与依赖已通过窗口构建；固定源包和原件仍在。保留项不是已删除或全量迁移成功，不影响当前消费者脱离旧路径。
- 废弃 bootstrap 内的 rustup 符号链接先暂停清理，随后核实均指向同目录目标，单独删除链接本身后才删除其普通目录，没有跟随链接删除外部文件。
- 原文件清单核对程序最初把缓存标记误匹配为文件名，校正为 Cargo 标准 Signature 后才继续，没有在失败检查后删除该批次。
- 最后一次压缩遇 CLI EXE 临时占用，实际 ZIP 缺该文件却打印完成路径。补齐 package.ps1 逐项 ZIP 文件 SHA256 校验，成功包全部匹配；实际生成缺 CLI ZIP 的故障注入被拒绝，且没有生成最终 SHA256SUMS。此前已发布 0.5.0 附件完整核验，不受本轮失败影响，不改 Release。
