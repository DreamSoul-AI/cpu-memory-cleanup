# 二、按钮到工作集整理的静态条件链

至此连接了所分析版本的条件调用链。静态代码中，从事件函数到该清理槽位是普通同步调用，没有在两者之间创建“清理工作线程”或等待动画结束。组件另有独立Enum任务维护读数，不应把它误认成工作集清理任务。是否以及何时由用户当前窗口触发这些路径，仍未做运行时验证。

# 三、附带软件操作与显示口径
一键加速函数在工作集分支后调用EXE RVA 0xda050，按软件项标志调用CProcMgr虚表+0x40。对应DLL 0x8a2c0查找软件项后调用其虚表+0x30。在CProcItem实现中，该项为0x87090，经0xe645a以PROCESS_TERMINATE打开进程，并调用TerminateProcess。它是条件性的软件项路径，不是每个点击都必定结束程序，也不是工作集裁剪的一部分。本轮没有执行该路径，没有修改本项目不结束进程的约定。

独立Enum任务经DLL RVA 0x8ab50调用0x8b2c0，通过GlobalMemoryStatusEx更新物理总量、可用量等字段。CProcMgr虚表+0x50的0x8a580返回总量减可用量。窗口0xd9760再基于更新前后的容量计算非负下降差值，0xd9800读取显示比例并设置呈现状态，另有显示定时器。未完整还原比例算法和当前渲染时序，不把这里的窗口差值等同于我们固定Run的前后快照差，也不据静态定时器推出360在本机用了几秒动画。
