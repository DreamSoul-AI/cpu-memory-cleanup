# 三、后续建议与未覆盖项

本轮范围完成后先由用户试用当前Rust正式页面。若仍反馈“按下卡顿”，优先按同一Run的点击、受理、原生耗时和页面帧间隔定位；不得再先调动画掩盖真实等待。本次原生时间占绝大多数，尚未证明换语言缩短同负载清理时间，不承诺复刻360全部速度。

- **产品试用反馈**：核对真实日常使用时点击响应、效果及回升感受，再决定是否改主流程，不预加功能选项。
- **平台验证**：定向/批次真实动作、自动规则、不同Windows版本目前未实机验收。需要具体范围和次数后再运行，隔离测试不替代这些证据。
- **分发**：当前0.4.0为本地候选；签名、可分发二进制、GitHub Release和crate发布另行决定。本轮不发布PyPI/crates.io，不推送远端。

Linux系统接入、AI资源Agent、跨应用优先级和限额仍为候选方向，未纳入本轮。Windows同样具有资源管理能力，Linux也可能换页卡顿；相关机制与来源保留在通用调研及历史讨论记录，不把“Linux可以、Windows不行”作为开发前提。
