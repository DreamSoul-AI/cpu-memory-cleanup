# 一、本版范围

发布内容为 Rust Package、六个 CLI/Agent 工具及 localhost 网页，统一使用真实系统后端。用户双击 CMD 打开网页，点击绿色按钮执行一次真实工作集整理。实时读取、原始结果和独立动效分别管理。自动规则默认关闭。

保留当前默认串行核验策略，不采用实验候选替换绿色按钮，不增加新清理机制、独立桌面 UI 或跨平台功能。不发布 crates.io/PyPI。

## （一）REL-01 固定源码与版本说明

状态：文档整理与第二次一致性复核已完成，源码提交及最终评审版本仍待固定。

- README 分开普通使用、开发检查和交付状态，统一架构、结构设计、调研与候选状态

- 明确 Rust 迁移不兼容旧 Python 导入及部分旧 CLI 选项，历史 v0.2.0/Pages 演示不代表本版

验收：相对链接有效，无现行回弹合同冲突，无“候选未实测”等过期结论，工作区差异可追踪。

## （二）REL-02 验证最终交付产物

状态：已完成原仓库检查、解压包真实验收和CMD启动核对，见[发布包验收](<运行记录 Run Record/2026-11-03 Windows发布包验收.md>)。

1. 对固定源码运行本地完整检查，保存环境、版本、提交、日志及产物 SHA256。若原仓库仍受权限限制，导出副本必须核对输入一致并注明范围
2. 在允许的环境停止旧服务，启动最新正式产物，核对 CLI、HTTP 与库的版本及构建标识一致，确认 CMD 不留终端、不会复用旧构建
3. 内置浏览器做真实读取及一次完整按钮验收，核对结果立即出现、下降和回弹衔接、错误事实保留，自动规则关闭。未获工具访问许可时记为阻断，不绕过
4. 准备 Windows x64 ZIP，沿用当前入口的相对结构：scripts/memory-cleanup.cmd、target/release/memory-cleanup.exe、target/release/cpu-memory-cleanup.exe，另附MIT及简短使用说明。不直接把依赖该相对结构的CMD放到EXE旁边冒充可用包。解压后用户双击CMD，不要求安装Rust、Node或Python
5. 在含空格的普通用户可写解压目录验收入口、真实读数、一次按钮操作、记录保存及停止服务，核对无遗留终端和未打包运行依赖。固定同一EXE摘要，静态网页资源随EXE嵌入，不依赖源码目录

验收：使用待发布 ZIP 内的产物完成启动及真实旅程，记录对应摘要。不以开发目录运行成功替代 ZIP 验收。
